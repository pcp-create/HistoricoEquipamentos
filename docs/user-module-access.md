# Acesso aos módulos

Todos os funcionários com acesso liberado têm acesso a CRM, Assistência Técnica,
Suprimentos, Equipamentos, Tarefas, Programação de OSs e Portal Técnico.

A seleção individual de módulos foi removida do cadastro. As seleções antigas
armazenadas pela migração 048 não restringem mais cartões, páginas ou APIs.
Funcionários novos recebem o mesmo acesso, sem configuração adicional ou migração.

Contas bloqueadas continuam sem acesso. A troca obrigatória de senha, as ações
exclusivas de administradores e as regras de responsabilidade pelas OSs continuam
sendo verificadas. O Portal Técnico apresenta as OSs atribuídas ao usuário.
